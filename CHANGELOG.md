### Changed
- **Kit tooling and scan:** `clean_scan.py` identifies image files by their magic bytes (PNG, JPEG, GIF, WebP) and counts them on a `BINARY <n>` line outside `TOTAL` instead of `SKIP binary`, so `--release` can pass with Folio's icons; any other NUL-bearing file still skips, and there is no allow-list. A term of exactly 4 characters in the `--terms-file` list is matched case-sensitive and whole-word. `tools/README.md` lists every local CI step in run order, checked against `STEPS` by `tests/test_ci_local.py`.
- **Accelerator:** the builder plugin is `agent-builder` with the command `/build-agent` (folder, manifests, marketplace, registry and every reference); the hook rates come from `pricing.json` (a missing or malformed file raises `PricingError`, and the audit hook then keeps the record and leaves the budget untouched); the generated `README.md` states the real plugin count; example commits are by `Example Author`; the hard-coded homepage and release URLs are gone; vendored prose lines reworded in neutral wording with the same meaning.
- **Folio:** the About texts come from Folio's local config and are empty by default; the brand title, web manifest and `pyproject.toml` are generic; `tests/KEEP.md` line pointers follow `folio/web.py`.
- **Second brain:** keyed name hashes: a `second_brain.name_hashes` entry is the first 16 hex characters of HMAC-SHA256 over the folded word with a local 32-byte scan key, so a word list no longer reverses it. **Contract change:** old unkeyed entries must be re-hashed. `sb --init-key` creates the key once at `~/.config/grok-kit/scan.key` (0600, folder 0700); `sb --hash-name` prints hashes without echoing a word; with entries set, search and `--doctor` fail closed on a missing or unsafe key. Tests in `second-brain/tests/test_scan_key.py`.
- **Dev-lead:** `agents/dev-lead/AGENT.md` points at its skill and routine files; a skill name clash and the create-a-new-agent option both use `kit.collision_suffix`.
- **Runner:** the tests that start `run-claude.sh` or `bin/cr` run inside the sandbox; comments, docstrings, messages and docs are generic; `backlog.reserve_slots` / `reserve_opus` replace the source's reserve keys; `run-claude.sh <label> <worktree>` reads `<prompts_dir>/<label>.md`; `load_config` fills every missing safe-limit key from `policy.DEFAULTS` (your values are never changed); `sched.loop()` and `sched.launch()` refuse unless `runner.enabled` is `true`; `/usage` probes stay at least 30 minutes apart (the near-park re-probe 5); quiet hours are on by default (01:00-07:00, UTC unless `tz` is set).
- **Licenses and pins:** `EXTERNAL-DEPENDENCIES.md` lists the pinned versions, platforms and checksums; `VENDORED.md` has Apache-2.0 in every license column.

### Removed
- **Kit tooling and scan:** the dead `run-claude.sh` guard check in the `runner-k5` step; it always runs `runner/tests/k5`, and a red suite is a `FAIL`.
- **Runner:** host-specific variable names from the `/usage` probe, and the source's leftover names from the runner's static test (now checked by digest).

### Fixed
- **Overwrite planner:** with `second_brain.name_hashes` set, the checkpoint 3 doctor step reads the scan key the way `sb --doctor` does instead of reporting that the doctor could not run; a missing or unusable key still fails closed, and the key stays out of the plan. Tests in `tests/overwrite/test_scan_key.py`.
- **Licenses and pins:** `tests/test_licenses.py` allows the company word in an explicit list of NOTICE files, so Folio's NOTICE copy passes and a NOTICE file anywhere else still fails.
- **Kit tooling and scan:** `clean_scan.py` starts gitleaks and trufflehog without any `GITLEAKS_*` or `TRUFFLEHOG_*` environment variable, and the structure tests fail on a tracked secret-scanner ignore or config file or an inline suppression marker; build ids are gone from the kit's comments and test texts.
- **Accelerator:** more vendored lines reworded in neutral wording with the same meaning (one skill file renamed `domain-research-searches.md`), the sample keys of two behaviour scenarios use a fake shape secret scanners do not match, and the dated internal learning notes are removed with their references; every change is listed in `VENDORED.md`.
- **Accelerator:** one more line in each of five skill and agent docs (license compatibility, PySpark layout, Go pack, Perl pack, abuse-case elicitor) is reworded in neutral wording with the same meaning; listed in `VENDORED.md`.
- **Folio:** the loopback URL test joins its userinfo sample at run time.
- **Onboarding and docs:** `README.md` states that the final release gate is external to the kit and that the kit has no client/employer coverage; `VENDORED.md` gives the full 40-character source commit for the accelerator, Folio and runner rows and `n/a` with the reason for the non-git sources and lists the kit changes to vendored files; the changelog is assembled here.
