# External dependencies

Only public, pinned, checksummed tools. Nothing else is downloaded. Your Grok Bot checks what you already have first and installs only what is missing (after your OK).
Machine-readable pins: `tools/pins.json`. Check a downloaded file with `python3 tools/verify_pins.py <pin-name> <file>`; `python3 tools/verify_pins.py --release` fails if any required pin is still a placeholder.

Notes:
- Claude Code on npm is a small wrapper plus one platform package (an `optionalDependency`); both integrities are pinned. The native installer (https://claude.ai/install.sh) checks the same release's manifest; its per-platform sha256 values are listed as optional pins. The manifest also has a detached signature (`manifest.json.sig`, key fingerprint 31DDDE24DDFAB679F42D7BD2BAA929FF1A7ECACE); the kit does not verify it.
- Node.js: the kit checks the sha256 from `SHASUMS256.txt`. Verifying the signature on that file needs the Node.js release keys (https://github.com/nodejs/release-keys); the kit does not ship or import any key.
- Release-gate dev tools (optional, not installed by the kit): gitleaks 8.21.2 linux_x64 tarball sha256 `5bc41815076e6ed6ef8fbecc9d9b75bcae31f39029ceb55da08086315316e3ba`; trufflehog 3.88.0 linux_amd64 tarball sha256 `92764b90a07a947b5f0a4b8c06c37e9485dcdd7c4f456b35e3a5ee48e9b66efa`.
