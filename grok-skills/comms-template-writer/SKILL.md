  Use this when asked to write a reusable message template for parents,
  students or venues (newsletter, reminder, reply).
---
# Steps
1. Ask for the purpose, tone and channel if not given.
2. Write the template with placeholders (`<parent-greeting>`, `<date>`). Never fill in real names, contact details, health or payment information.
3. Save it as a draft note in `<channel>/comms/` with the standard front matter, after I confirm the file name.
4. Remind me that sending happens from my roster or mailing system, not from the second brain.
5. Never send anything from this skill.
