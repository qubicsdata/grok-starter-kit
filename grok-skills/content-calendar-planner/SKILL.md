# Steps
1. Read the campaign note and the current calendar in `<channel>/marketing/` (and any existing campaign I already run, from `onboarding/current-state.md`). Link to existing campaigns; never duplicate them.
2. Propose a calendar table: date, platform, theme, draft note, status. Follow my term cycle (intakes, new-group launches, socials, festival, summer) and my posting preferences from memory.
3. Draft each post as a note in `<channel>/marketing/social/` from the matching template, with the standard front matter and `status: draft`. Take studio, price and link values from my private business profile with `python3 tools/business_profile.py fill` when I have one; never copy the profile itself into a note.
4. Flag any post that would show a minor: no names or faces without a guardian's written consent on record, and I decide.
5. Never publish, schedule or send. Present drafts for my approval; I post them myself.
