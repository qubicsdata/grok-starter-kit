# Steps
1. Read the campaign note and the current calendar in `<channel>/marketing/` (and any existing campaign I already run, from `onboarding/current-state.md`). Link to existing campaigns; never duplicate them.
2. Propose a calendar table: date, platform, theme, draft note, status. Respect my posting preferences from memory.
3. Draft each post as a note in `<channel>/marketing/social/` with the standard front matter and `status: draft`.
4. Flag any post that would show a child: it needs recorded photo consent, and I decide.
5. Never publish, schedule or send. Present drafts for my approval.
