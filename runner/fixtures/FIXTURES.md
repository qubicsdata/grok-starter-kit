# Fixtures (synthetic only)

Every fixture here is invented: example emails (`user@example.com`), "Example Org", `/home/user/example-project`, zero UUIDs. Never paste a real `/usage` capture or a real stream log here. A privacy test fails the build on any email outside example domains, any non-zero UUID, any home path other than `/home/user/`, or bidi control characters.

Every fixture in this folder and in `runner/tests/fixtures/` is written by `runner/tests/make_synthetic_fixtures.py` (run it after changing it; `--check` reports a missing or stale file). `runner/tests/test_fixtures_generated.py` fails on any fixture the generator does not produce, and `runner/tests/test_fixture_privacy.py` scans all of `runner/` (contents and names: example-only emails, zero UUIDs, `/home/user` only, no bidi or other control characters, no `*_real_*` names).

## Shapes
- `usage_screen_synthetic.txt`: what `claude -p "/usage"` prints. A header line (CLI version, model, plan, project path), a tab bar, then three blocks: current session, current week (all models), current week (Fable). Each block is a label, a 50-column bar with "NN% used", and a "Resets <time> (<tz>)" line.
- `rate_limit_events_synthetic.jsonl`: one JSON object per line as found in a `--output-format stream-json` log: `type: "rate_limit_event"` with `rate_limit_info` holding `status` (`allowed`, `allowed_warning`, `rejected`), `rateLimitType`, `resetsAt` (epoch seconds), `utilization` (0..1), `unifiedWindows` (`five_hour`, `seven_day`, each with `utilization` and `resetsAt`) and `overageStatus`. The field set is what the runner's parser reads, checked by `runner/tests/test_stream_fixtures.py`.
- `stream_allowed_synthetic.jsonl`, `stream_rejected_synthetic.jsonl`: whole `claude -p --output-format stream-json --verbose` logs: a `system`/`init` line, an `assistant` turn with `usage`, the `rate_limit_event` lines (the allowed stream repeats one, as real streams do; the rejected one goes `allowed_warning` then `rejected`) and a compact `result` line (`"type":"result"`, no spaces: the parser matches that text). The rejected result is an error with `api_error_status` 429, so the runner logs a limit hit and parks until `resetsAt`.
- Reset times: the `/usage` screen prints wall-clock times; the parser reads them in the machine's local time zone and ignores the `(zone)` label, while `rate_limit_event` carries exact epoch seconds.
